Блок 2: Тригонометрия

Систематизация знаний за 10 класс: формулы приведения, основные тождества, уравнения.

📘 Опорный материал

1. Радианная мера угла

$180^{\circ} = \pi \text{ рад}$      $x^{\circ} = x \cdot \frac{\pi}{180}$
Важно: Запомните ключевые точки: $30^{\circ} = \frac{\pi}{6}$, $45^{\circ} = \frac{\pi}{4}$, $60^{\circ} = \frac{\pi}{3}$, $90^{\circ} = \frac{\pi}{2}$.

2. Знаки функций по четвертям

  • I четверть ($0 < \alpha < \frac{\pi}{2}$): все функции (+)
  • II четверть ($\frac{\pi}{2} < \alpha < \pi$): sin (+), cos (-), tg (-), ctg (-)
  • III четверть ($\pi < \alpha < \frac{3\pi}{2}$): tg (+), ctg (+), sin (-), cos (-)
  • IV четверть ($\frac{3\pi}{2} < \alpha < 2\pi$): cos (+), sin (-), tg (-), ctg (-)

3. Формулы приведения

Мнемоническое правило: меняется ли название функции? Если опорная точка — вертикальная ось ($\frac{\pi}{2}, \frac{3\pi}{2}$) — да («киваем головой»). Если горизонтальная ($0, \pi, 2\pi$) — нет («мотаем головой»). Знак ставим по исходной функции.
Примеры: $\sin(\pi - \alpha) = \sin\alpha$; $\cos(\frac{\pi}{2} + \alpha) = -\sin\alpha$.

4. Основные тригонометрические тождества

$\sin^2\alpha + \cos^2\alpha = 1$
$1 + \text{tg}^2\alpha = \frac{1}{\cos^2\alpha}$      $1 + \text{ctg}^2\alpha = \frac{1}{\sin^2\alpha}$
$\text{tg}\alpha = \frac{\sin\alpha}{\cos\alpha}$      $\text{ctg}\alpha = \frac{\cos\alpha}{\sin\alpha}$

5. Формулы двойного аргумента

$\sin 2\alpha = 2\sin\alpha\cos\alpha$
$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$

6. Формулы суммы и разности

$\sin\alpha \pm \sin\beta = 2\sin\frac{\alpha \pm \beta}{2}\cos\frac{\alpha \mp \beta}{2}$
Подсказка: Сумма синусов дает произведение синуса (на полусумму) и косинуса (на полуразность).
$\cos\alpha + \cos\beta = 2\cos\frac{\alpha + \beta}{2}\cos\frac{\alpha - \beta}{2}$
$\cos\alpha - \cos\beta = -2\sin\frac{\alpha + \beta}{2}\sin\frac{\alpha - \beta}{2}$
Подсказка: Обратите внимание: сумма косинусов — это всегда два косинуса, а разность косинусов — это всегда два синуса. В формуле разности перед дробью появляется минус.
$\text{tg}\alpha \pm \text{tg}\beta = \frac{\sin(\alpha \pm \beta)}{\cos\alpha \cos\beta}$

✏️ Разбор примеров

Алгоритм решения типовых заданий перед самостоятельной работой.

Пример 1. Упростите: $\sin(\frac{3\pi}{2} - \alpha)$
Используем формулу приведения. Угол $\frac{3\pi}{2}$ лежит на вертикальной оси — функция меняется на кофункцию (синус на косинус). Угол $\frac{3\pi}{2} - \alpha$ находится в III четверти, там синус отрицательный.
$\sin(\frac{3\pi}{2} - \alpha) = -\cos\alpha$.
Ответ: $-\cos\alpha$.
Пример 2. Вычислите: $\sin 150^{\circ}$
Представляем как $\sin(180^{\circ} - 30^{\circ})$. II четверть, синус положительный, функция не меняется.
$\sin(180^{\circ} - 30^{\circ}) = \sin 30^{\circ} = 0.5$.
Ответ: 0.5.
Пример 3. Решите уравнение: $2\cos^2 x - 1 = 0$ на $[0; 2\pi]$
Узнаем формулу косинуса двойного угла: $\cos 2x = 0$.
$2x = \frac{\pi}{2} + \pi k$
$x = \frac{\pi}{4} + \frac{\pi k}{2}$.
Отбираем корни на промежутке $[0; 2\pi]$: $\frac{\pi}{4}, \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{7\pi}{4}$.
Ответ: $\frac{\pi}{4} + \frac{\pi k}{2}, k \in \mathbb{Z}$.

Легкий
Задание 1. Упростите выражение: $\cos(\pi + \alpha) + \sin(\frac{\pi}{2} + \alpha)$
Решение:
$\cos(\pi + \alpha) = -\cos\alpha$ (III четв., гориз. ось, знак минус)
$\sin(\frac{\pi}{2} + \alpha) = \cos\alpha$ (II четв., верт. ось, функц. меняет знак, но угол $(\frac{\pi}{2}+\alpha)$ дает плюс при переходе во II четв.)
$-\cos\alpha + \cos\alpha = 0$.
Ответ: 0.
Легкий
Задание 2. Найдите значение выражения: $2\sin\frac{7\pi}{6} - \sqrt{3}\cos\frac{5\pi}{3}$
Решение:
$\sin\frac{7\pi}{6} = \sin(\pi + \frac{\pi}{6}) = -0.5$
$\cos\frac{5\pi}{3} = \cos(2\pi - \frac{\pi}{3}) = 0.5$
$2 \cdot (-0.5) - \sqrt{3} \cdot 0.5 = -1 - \frac{\sqrt{3}}{2}$.
Ответ: $-1 - \frac{\sqrt{3}}{2}$.
Средний
Задание 3. Известно, что $\sin\alpha = \frac{3}{5}$, $\alpha \in (\frac{\pi}{2}; \pi)$. Найдите $\text{tg}\alpha$.
Решение:
$\cos^2\alpha = 1 - \sin^2\alpha = 1 - \frac{9}{25} = \frac{16}{25}$. Так как $\alpha$ во II четверти, $\cos\alpha = -0.8$.
$\text{tg}\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{0.6}{-0.8} = -0.75$.
Ответ: $-0.75$.
Средний
Задание 4. Решите уравнение: $\sin x - \sqrt{3}\cos x = 0$
Решение:
Это однородное уравнение 1-й степени. Делим на $\cos x$ (он не равен 0, иначе и синус был бы 0, что невозможно):
$\text{tg}x - \sqrt{3} = 0 \Rightarrow \text{tg}x = \sqrt{3}$.
$x = \frac{\pi}{3} + \pi k, k \in \mathbb{Z}$.
Ответ: $\frac{\pi}{3} + \pi k, k \in \mathbb{Z}$.
Средний
Задание 5. Решите уравнение: $\sin x + \sin 3x = 0$
Решение:
Применяем формулу суммы синусов: $2\sin\frac{x+3x}{2}\cos\frac{x-3x}{2} = 2\sin 2x \cos(-x) = 2\sin 2x \cos x = 0$.
$4\sin x \cos^2 x = 0$.
Либо $\sin x = 0 \Rightarrow x = \pi n$, либо $\cos x = 0 \Rightarrow x = \frac{\pi}{2} + \pi k$.
Объединяя серии: $x = \frac{\pi n}{2}, n \in \mathbb{Z}$.
Ответ: $\frac{\pi n}{2}, n \in \mathbb{Z}$.
Сложный
Задание 6. Решите уравнение: $\cos 2x = \sin x$ на отрезке $[-\pi; \pi]$
Решение:
Замена синуса через косинус: $1 - 2\sin^2 x = \sin x \Rightarrow 2\sin^2 x + \sin x - 1 = 0$.
Пусть $t = \sin x$. Корни квадратного уравнения: $t_1 = 0.5, t_2 = -1$.
1) $\sin x = 0.5 \Rightarrow x = (-1)^k \frac{\pi}{6} + \pi k$. На отрезке это $-\frac{5\pi}{6}, -\frac{\pi}{6}, \frac{\pi}{6}, \frac{5\pi}{6}$.
2) $\sin x = -1 \Rightarrow x = -\frac{\pi}{2} + 2\pi k$. На отрезке это $-\frac{\pi}{2}$.
Ответ: $-\frac{5\pi}{6}, -\frac{\pi}{2}, -\frac{\pi}{6}, \frac{\pi}{6}, \frac{5\pi}{6}$.
